CSS Positioning

static (mặc định): không thể thay đổi vị trí bằng top, left, right, bottom

relative: chỉnh vị trí so với vị trí gốc (static)

absolute: chỉnh vị trí so với phần tử cha gần nhất

fixed: chỉnh vị trí so với cửa sổ trình duyệt
